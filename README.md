# Hi, I'm David

I study applied physics and mathematics at NTNU. I like the part of maths that is used to make decisions: expected value, statistics and simulation. I also build tools with Python, Swift and LLM agents.

## What I work on

- **LLM Wiki:** an agentic knowledge system in Obsidian where an LLM agent ingests sources, maintains a markdown wiki and runs scheduled checks. Private, because it holds personal data.
- **[NotchTodo](https://github.com/popovicdavid/notch-todo):** a native macOS app in Swift that shows a todo list in the notch.
- **Poker bot:** built in Python with a friend. I work on the decision logic, where Monte Carlo simulation estimates equity and is compared with pot odds.
- **[popovicdavid.github.io](https://github.com/popovicdavid/popovicdavid.github.io):** my website, with the flow field in the header drawn from a system of differential equations.
